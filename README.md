# Моя панель

Личная панель Марины: задачи по проектам, события, привычки и дальше — дневник, спорт, бильярд, чтение, английский, блог.

## Что уже работает (шаг 1)

- Меню-аквариум с лучами света и рыбками; на телефоне — нижнее меню.
- «Сегодня»: задачи карточками по проектам, фильтр «Все / Личное / Работа» и по проекту, сфера с водой (наполняется, когда отмечаешь задачи), события дня, привычки, быстрая запись во входящие, «Закрыть день».
- «Задачи»: сворачиваемый выбор списка (входящие, сегодня, предстоящие, проекты), вид списком, канбан, отчёт по работе за день (копировать / открыть письмо).
- Добавление и редактирование задач: проект, дата, время, срок, теги (выбор из списка, новый тег или без тегов), статус, удаление.
- Новые проекты и события, привычки, имя в настройках.
- Бэкап: скачать файл и восстановить из файла.
- Работает без интернета после первого открытия, ставится на экран «Домой» на айфоне.

Данные хранятся в базе Supabase (вход по почте и паролю), в браузере — копия для быстрой работы и офлайна. Мак и айфон видят одно и то же. Каждую ночь копия данных уходит в отдельный приватный репозиторий.

## Как устроено

Без сборки и установки: обычные HTML, CSS и JavaScript-модули.

```
index.html            — страница
css/app.css           — весь стиль и «вода»
js/app.js             — навигация и обработка кнопок
js/store.js           — данные и синхронизация с базой
js/remote.js          — вход и запросы к Supabase
js/config.js          — адрес базы и публичный ключ
js/util.js            — даты и мелочи
js/ui/                — меню, окна, иконки, плавное обновление экрана
js/pages/             — экраны
supabase/schema.sql   — схема базы для следующего шага
sw.js, manifest       — офлайн и установка на телефон
```

## Где живёт

- Сайт: GitHub Pages из этого репозитория (ветка main).
- База: Supabase, схема в `supabase/schema.sql`, доступ к строкам только у владельца (RLS).
- Бэкап: приватный репозиторий `life-panel-backup`, обновляется каждую ночь.
